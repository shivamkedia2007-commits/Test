# AgriSaathi

Build this landing page as a responsive React + Tailwind CSS page. Recreate the provided design as accurately as possible. Use reusable components for the navbar, hero section, farmer trust section, and feature cards. Make the navbar responsive. Make Get Started navigate to the marketplace, Login navigate to /login, Sign Up navigate to /signup, Marketplace navigate to /marketplace, and Learn More scroll to the relevant section. Do not add features that aren't in the design.
